# Luna build iteration with a fixed verifier, 18 October 2026

This trial tested whether a Luna agent could iterate on an extension build while a separate, unchanged verifier checked its final archive. The target was pg_stat_monitor 2.4.0 with PostgreSQL 18.6 on Linux x86-64. Root supplied the Alpine final-archive verifier and focused GitHub workflow; Luna alone edited the Docker builder, packaging script and [research record](../../scripts/pg_stat_monitor/RESEARCH.md). The verifier checked the archive checksum and layout, ELF dependencies, relocation, ordinary-user PostgreSQL startup with `shared_preload_libraries`, `CREATE EXTENSION`, and a recorded query. Neither the project nor its archive was added to advertised support.

The first four [CI runs](https://github.com/BernieSumption/pg_binaries/actions/workflows/pg-stat-monitor-luna-trial.yml) exposed, in order, a shallow-fetch tag check, an incorrect extracted source directory, missing OpenSSL development headers during compilation, and a checksum-sidecar filename mismatch. Luna diagnosed and fixed each from its own CI log without a build change from root. The fifth [run 39138856521](https://github.com/BernieSumption/pg_binaries/actions/runs/39138856521) passed the fixed verifier. It produced archive SHA-256 `83cd9daab190109ca5f09c564f0968b20cd06df720ffe13c2cf818607276285c`; downloaded bytes matched this hash. The static report bound it to PostgreSQL archive SHA-256 `f89a7047812324b85c3b0bb29a3118fc55a492b17956f1fe0d74d1788d33d680` and passed inspection of 185 ELF files, including `lib/pg_stat_monitor.so`. The five runner jobs totaled 172 seconds; the first began at 15:00:55 UTC and the passing fifth finished at 15:05:42 UTC. Individual causes, fixes and job times are in the research record.

One setup intervention was needed: `workflow_dispatch` returned 404 because the trial workflow existed only on `spike`, so root added a narrow push trigger. The local Docker daemon was unavailable; all compilation and compiled execution occurred in Docker on standard GitHub runners. The fixed verifier itself was prepared by root before Luna began, and this trial does not measure whether Luna can independently design a sound verifier. The result supports assigning Luna bounded PGXS build and packaging iterations once the target contract and verifier are fixed. It does not establish full platform/version coverage, redistribution review, publication-profile evidence or unattended extension selection.
