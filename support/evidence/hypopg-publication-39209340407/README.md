# HypoPG selected Linux publication verification

[GitHub Actions run 39209340407](https://github.com/BernieSumption/pg_binaries/actions/runs/39209340407) tested source revision `72af08897535d6a0c000abfde7728c80f87a9f60` on 2026-10-19. The shared Linux changed-profile scheduler selected HypoPG 1.4.3 against PostgreSQL 15.19, 16.15, 17.11 and 18.6 on x86-64 and arm64. Each target built an extension archive against a checked PostgreSQL archive, then verified both final archives on a separate runner in Alpine 3.22. All eight verification jobs passed.

Each target's `core-resolution.json` in the temporary CI artifact reports `origin: reused`; the resolver checked the candidate archive and its build inputs before use. The retained receipts and records bind the exact core and extension archive hashes to their target, profile revision, environment and case result. The eight record files are under `support/verification/`; receipts, step outcomes and static-analysis reports are under this directory by architecture and PostgreSQL version.

The artifacts named `hypopg-linux-selected-<PostgreSQL version>-<architecture>-39209340407` were downloaded and independently imported with `tools/import_linux_hypopg_publication.py`. All 32 retained receipts, step files, reports and records matched the corresponding CI artifact files byte for byte. The full local suite passed 801 tests. The run used 13.1 GitHub-hosted runner minutes: 7.7 for builds, 3.5 for verification and 1.9 for selection and planning. [Run 39207998584](https://github.com/BernieSumption/pg_binaries/actions/runs/39207998584) rebuilt all eight cores and used 31.5 runner minutes; its isolated jobs passed, but its architecture-only retained paths could not hold several PostgreSQL versions from one run. Those paths were corrected before this final run.

These results establish the selected HypoPG Linux build and verification path. They do not establish release eligibility for other projects or targets.
