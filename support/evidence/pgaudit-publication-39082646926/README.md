# pgAudit 18.0 Linux publication verification

[Run 39082646926](https://github.com/BernieSumption/pg_binaries/actions/runs/39082646926) passed on native x86-64 and arm64 Linux runners against PostgreSQL 18.6. Each job built unmodified pgAudit source, relocated its final archive with the exact PostgreSQL core into Alpine 3.22, checked ELF dependency closure, and verified DDL, write and read audit logging. The imported [x86-64](x86_64/current-receipt.json) and [arm64](arm64/current-receipt.json) receipts and records bind the result to archive hashes and the current profile. The upstream-only status of Linux dependency packages remains a separate release-eligibility question.
