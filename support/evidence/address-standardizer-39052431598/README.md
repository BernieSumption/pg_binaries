# Address Standardizer Linux feasibility run

This was a feasibility probe using Ubuntu build packages. It did not assemble the normal relocatable extension package or run the publication verification profile. Its result does not establish the declared platform or PostgreSQL matrix, dependency provenance or the pending upstream-only source-rule interpretation.
