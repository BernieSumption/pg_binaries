# Checked pgvector archive reuse trial

The [first scoped retry, run 39164244369](https://github.com/BernieSumption/pg_binaries/actions/runs/39164244369), downloaded the previously verified pgvector 0.8.7 Linux x86-64 archive from run 39163686051. It checked the independently pinned archive SHA-256 and sidecar, then rebuilt the current Docker image and asked the work queue whether the archive's build inputs still matched. The queue rejected it because the Docker image IDs differed, despite the same Ubuntu base digest. The job rebuilt pgvector and passed fresh-runner Alpine verification. Its 38-second build and 32-second verification jobs established a safe fallback, but showed that a Docker image ID was too sensitive for useful reuse.

The recipe now pins the Ubuntu 22.04 Linux amd64 base digest and identifies the builder by its sorted installed Debian package names, versions, architectures and statuses. The package inventory is taken from the completed image used for compilation. The exact Dockerfile, package-inventory helper, source pin and other recipe files also contribute to the build-input identity. An image ID remains in archive metadata for diagnostics but no longer controls reuse.
