# Extension release review, 2026-10-17

This review checks the selected source releases against the [version rule](../../specs/functional.md#determining-postgres-and-extension-versions-to-support). It identifies intended versions; it does not establish build, runtime, redistribution or publication eligibility. PostgreSQL selection is recorded in [the release snapshot](../postgresql-releases.json).

- **pgvector:** 0.8.7 is the latest stable release found in the [upstream changelog](https://github.com/pgvector/pgvector/blob/master/CHANGELOG.md). PostgreSQL 15–18 compatibility remains subject to archive tests.
- **PostGIS:** 3.6.4 is the latest stable 3.x release in [upstream source releases](https://postgis.net/development/source_code/); the [compatibility table](https://www.postgis.net/development/compatibility/) includes PostgreSQL 15–18. The 3.4 and 3.5 lines are the same major, so the current rule does not retain them.
- **PostGIS TIGER Geocoder:** 2025.2 is the latest separate release found in the [upstream announcement](https://postgis.net/2026/08/PostGIS-Tiger-Geocoder-2025.2/). It declares PostgreSQL 16+ and PostGIS 3.6+; PostgreSQL 15 is outside its documented range.
- **HypoPG:** 1.4.3 is the latest release found in the [upstream announcement](https://www.postgresql.org/about/news/hypopg-143-is-out-3326/), which states PostgreSQL 9.2+.
- **collection:** The [upstream release list](https://github.com/aws/pgcollection/releases) has 1.1.1 as the latest 1.x and 2.1.3 as the latest overall. [PGXN](https://pgxn.org/dist/pgcollection/1.0.0/) dates the first 1.x release to 2025-04-03 and the first 2.x release to 2026-03-20. Both majors qualify on the review date. The [current project README](https://github.com/aws/pgcollection) states PostgreSQL 14+.
- **pg_cron:** 1.6.8 is the latest release found in the [upstream history](https://github.com/citusdata/pg_cron/releases); its [README](https://github.com/citusdata/pg_cron) documents PostgreSQL support.
- **pg_ivm:** 1.16 is the latest release found in [upstream releases](https://github.com/sraoss/pg_ivm/releases); the [project README](https://github.com/sraoss/pg_ivm) states PostgreSQL 13–19.
- **pgaudit:** 1.7.1, 16.1, 17.1 and 18.0 are the selected releases for PostgreSQL 15, 16, 17 and 18 respectively. The [upstream compatibility map](https://github.com/pgaudit/pgaudit#postgresql-version-compatibility) ties each line to its server major; the [release list](https://github.com/pgaudit/pgaudit/releases) shows the branch releases.
- **pgTAP:** 1.3.4 is the latest release found in [upstream releases](https://github.com/theory/pgtap/releases). The project documents support for the selected PostgreSQL majors.
- **pg_jsonschema:** 0.3.4 is the latest [upstream release](https://github.com/supabase/pg_jsonschema/releases) and includes PostgreSQL 18 support. Its [Cargo manifest](https://raw.githubusercontent.com/supabase/pg_jsonschema/v0.3.4/Cargo.toml) uses pgrx 0.16.1. That version's [platform guide](https://raw.githubusercontent.com/pgcentralfoundation/pgrx/v0.16.1/README.md) lists tested Linux x86-64/arm64, macOS arm64 and Windows x86-64 targets; macOS x86-64 is expected as another Unix target but untested. The extension source declares no OS restriction found in this review. The upstream release workflow packages only Linux; this is not evidence that its source excludes the other project targets. Declare all five as intended and test builds before advertising them.

No pin change was established by this review. Each inventory refresh must repeat release discovery, compatibility review and the two-year major calculation. The pg_jsonschema platform expansion increases intended targets; the [backlog](../../GOAL_BACKLOG.md#version-policy-migration) tracks its unverified builds.
