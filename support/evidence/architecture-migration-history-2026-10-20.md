## Architecture migration

Implement the reviewed [architecture policy](../../policies/architecture.md) across the active build and verification paths. Preserve the functional and testing requirements. This project changes tooling, not the selected support set, and does not publish a release. Treat the phases below as the work to complete, choosing task order within each phase according to dependencies and CI cost.

This project also resolves the overlapping open work below: fresh-runner verification for active macOS and Windows extension paths; planner-to-CI dispatch and checked candidate retrieval; V3 verification-profile and job migration; V5 installation assembly and fixtures; V6 job-layout selection; and shared macOS evidence tooling. Reconcile those backlog entries as their work is completed. Retain separate items for unimplemented support coverage, redistribution decisions, release publication and post-release testing.
