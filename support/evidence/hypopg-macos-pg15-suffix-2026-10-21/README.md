# HypoPG macOS PostgreSQL 15 package failure

On 2026-10-21, selected HypoPG 1.4.3 publication runs [39519244308](https://github.com/BernieSumption/pg_binaries/actions/runs/39519244308) on arm64 and [39519243289](https://github.com/BernieSumption/pg_binaries/actions/runs/39519243289) on x86-64 built the unmodified extension against PostgreSQL 15.19. PGXS linked and installed `hypopg.so`, then the packaging script stopped because it required `hypopg.dylib`. Neither run produced an extension archive, so the subsequent verification cases failed. The retained [arm64](arm64-attempt.json) and [x86-64](x86_64-attempt.json) attempt files record the missing archive and failed cases. The build log establishes a packaging assumption to correct; it does not establish a source compatibility problem.
