# Selected-target HypoPG architecture trials

The selected-target workflows must build HypoPG 1.4.3 for a declared PostgreSQL release, verify the final archive with the exact core archive, and retain a record whose profile is still current. On 18 October 2026, the following GitHub-hosted runs passed. Their candidate artifacts were downloaded and re-imported locally; each importer checked archive hashes, receipts, reports and the current profile revision.

- Windows x86-64: PostgreSQL [15.19, run 39158208827](https://github.com/BernieSumption/pg_binaries/actions/runs/39158208827), [16.15, run 39158342661](https://github.com/BernieSumption/pg_binaries/actions/runs/39158342661), [17.11, run 39157842194](https://github.com/BernieSumption/pg_binaries/actions/runs/39157842194) and [18.6, run 39158353089](https://github.com/BernieSumption/pg_binaries/actions/runs/39158353089). Each [retained record](../verification/) passed the archive suite and PE static analysis on a fresh Windows runner. The records identify the exact core and extension SHA-256 values.
- macOS arm64: PostgreSQL [17.11, run 39157842257](https://github.com/BernieSumption/pg_binaries/actions/runs/39157842257) and [18.6, run 39158233512](https://github.com/BernieSumption/pg_binaries/actions/runs/39158233512). Each retained record passed the archive suite and Mach-O static analysis on a fresh macOS runner. Local import used both the build artifact containing the core and the verifier artifact containing the receipt and reports.
- Linux x86-64: PostgreSQL [17.11, run 39158295197](https://github.com/BernieSumption/pg_binaries/actions/runs/39158295197). Linux arm64: PostgreSQL [17.11, run 39158155956](https://github.com/BernieSumption/pg_binaries/actions/runs/39158155956). Each retained record passed the archive suite in a separate Alpine 3.22 container, including ELF dependency inspection and the HypoPG SQL probe. The same parameterized workflow selected the architecture and standard Ubuntu runner.

The eight successful runs used 78–88 runner-seconds each on Windows, 81–82 on macOS, and 189–230 on Linux, counting the selection job. Downloaded candidate artifacts occupied about 66–75 MiB per Windows run, 30 MiB for each macOS build artifact plus under 200 KiB for its verification artifact, and 58–59 MiB per Linux run. These measurements inform job grouping and targeted retry; they do not include the earlier failed Windows attempt or queued scope-gate jobs from profile edits.

The first selected Windows attempt, [run 39157276065](https://github.com/BernieSumption/pg_binaries/actions/runs/39157276065), built and verified the archive but could not emit its record because the workflow omitted the debug-symbol copy. The corrected run passed. The first Linux x86-64 run, [39157390115](https://github.com/BernieSumption/pg_binaries/actions/runs/39157390115), passed before architecture parameterization changed its profile revision; the current-profile refresh is run 39158295197.

These runs verify the listed targets and bytes. The Windows and macOS workflows still use checked-in core run-ID pins, Linux rebuilds core for each request, and the remaining active paths have not migrated. The planner-to-CI dispatch and build-input-aware candidate reuse work remains open in [the architecture backlog](../../GOAL_BACKLOG.md#architecture-migration).
