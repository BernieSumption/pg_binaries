# Selected macOS arm64 PostGIS archive trial

[Run 39659106649](https://github.com/BernieSumption/pg_binaries/actions/runs/39659106649) built PostGIS 3.6.4 for the selected PostgreSQL 18.6 macOS arm64 core. A separate macOS 15 runner relocated the exact archives, passed SQL probes for all four advertised PostGIS names and a raster-specific check, and passed Mach-O static analysis. The retained [attempt](arm64/18.6/attempt.json), [verifier report](arm64/18.6/postgis-macos-verification.json), [static report](arm64/18.6/static-analysis.json), and [runner image](arm64/18.6/runner-image.txt) identify the tested archive SHA-256 values and environment. The downloaded archive bytes match their checksum sidecars and the attempt record.

The evidence importer rejected this passing run because it expected the runner OS identity to end after `arm64`; the verifier reported `macOS-15.7.9-arm64-arm-64bit-Mach-O`. The importer now accepts that format. This run has no imported publication records because changing the importer changes its registered profile input. Rerun under the corrected profile after the macOS PostGIS path is generalized to the remaining selected PostgreSQL releases.
