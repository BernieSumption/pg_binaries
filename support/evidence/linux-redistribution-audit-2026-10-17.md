# Linux PostgreSQL redistribution evidence audit

The PostgreSQL 18.6 Linux x86-64 archive from [publication run 39003088887](https://github.com/BernieSumption/pg_binaries/actions/runs/39003088887) has SHA-256 `518f724176dd953fc2c373fef7d9a72939d459d80b16993db6c984dd2fbdc66b`. This is a historical pilot archive, not a proposed release asset. Its `LICENSES/inventory.json` maps PostgreSQL and 13 bundled runtime packages to payload paths and included copyright or licence files. None of the 14 components has a `redistribution_review` declaration, so [the release preflight](../../policies/releases.md) must reject this archive.

The runtime package identities recorded in the archive are `libc6` 2.35-0ubuntu3.15, `libgcc-s1` 12.3.0-1ubuntu1~22.04.3, `libicu70` 70.1-2, `liblz4-1` 1.9.3-2build2, `liblzma5` 5.2.5-2ubuntu1.1, `libssl3` 3.0.2-0ubuntu1.30, `libstdc++6` 12.3.0-1ubuntu1~22.04.3, `libuuid1` 2.37.2-4ubuntu3.6, `libxml2` 2.9.13+dfsg-1ubuntu0.14, `libxslt1.1` 1.1.34-4ubuntu0.22.04.5, `libzstd1` 1.4.8+dfsg-3build1, `musl` 1.2.2-4, and `zlib1g` 1:1.2.11.dfsg-2ubuntu9.2. Only `libc6` and `musl` record source-package names, source versions and exact source-archive URLs. The other package-page URLs do not identify the source material required for their exact binary versions.

The next review must identify each shipped component's applicable notices and source obligations from its included copyright text and exact source package, then record a version-keyed decision and any required files or links. PostgreSQL itself and `zlib1g` are candidates for early review because their included licence texts are short; this audit does not resolve their obligations. The final review must cover the actual archive bytes built for publication, including pgvector, PostGIS and TIGER Geocoder components, before advertising a download.
