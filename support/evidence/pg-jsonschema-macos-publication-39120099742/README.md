# pg_jsonschema macOS publication evidence

Runs 39120099714, 39120099799, 39120099729 and 39120099791 passed the archive suite and Mach-O analysis for PostgreSQL 15.19, 16.15, 17.11 and 18.6 on arm64. Run 39120099742 passed the same checks for PostgreSQL 18.6 on x86_64. Each run's imported record binds the extension archive to its exact pinned PostgreSQL core archive.

The PostgreSQL 15.19, 16.15 and 17.11 x86_64 runs (39120099867, 39120099800 and 39120099705) remain in progress. All candidates remain release-ineligible while the seahash notice and PostgreSQL core redistribution reviews are pending.
