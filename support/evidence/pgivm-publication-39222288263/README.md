# pg_ivm selected Linux publication run 39222288263

[GitHub Actions run 39222288263](https://github.com/BernieSumption/pg_binaries/actions/runs/39222288263) built and verified pg_ivm 1.16 against PostgreSQL 15.19, 16.15, 17.11 and 18.6 on Linux x86-64 and arm64. All eight target jobs passed on revision `de32190cc638fa45cc8b56f779a0e760be4b2f2e`.

Each selected artifact was downloaded and independently imported. The eight retained verification records bind the final pg_ivm archive SHA-256 to its exact PostgreSQL archive SHA-256, passing relocated SQL and static-analysis results, and the target's current verification profile. The checked PostgreSQL cores were reused from [run 39220109372](https://github.com/BernieSumption/pg_binaries/actions/runs/39220109372) for all eight targets; the downloaded core-resolution records identify that source run and the archive hashes.

Receipts, step outcomes and static-analysis reports are under `<architecture>/<PostgreSQL version>/`. The matching archive-bound records are in `support/verification/`.
