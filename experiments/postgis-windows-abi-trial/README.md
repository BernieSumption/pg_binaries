# PostGIS Windows cross-install trial

Created 2026-10-20 to test unmodified PostGIS 3.6.4 on the selected Windows PostgreSQL 18.6 archive. The manual `postgis-pilot.yml` workflow first builds PostgreSQL and PostGIS with the same MSYS2 MINGW64 toolchain. Run 39492045563 passed `CREATE EXTENSION postgis` and `postgis_full_version()` on that pair.

The selected Windows PostgreSQL core was built with MSVC. Runs 39495196354 through 39499432408 tried to build PostGIS directly against its PGXS files with GCC. The last run reached shared-library compilation, but the required MSVC-to-GCC build adapters became disproportionate. The previous adapter script remains in Git history.

The current `cross-install-probe.sh` follows the [upstream Winnie route](../../support/evidence/postgis-windows-upstream-build-review-2026-10-20.md): build against a matching MinGW PostgreSQL installation, then copy PostGIS DLLs and extension files into the selected MSVC PostgreSQL 18.6 archive. It tests the four selected SQL extensions against that exact core. A pass would establish the cross-toolchain module boundary; final archive verification would still be required.

Run 39602155946 on 2026-10-21 built PostGIS with raster, SFCGAL and topology. `CREATE EXTENSION postgis` passed against the selected MSVC core, then `postgis_raster` failed to load because Windows reported a missing procedure in a DLL. The run retained the build and selected-core installations. Its cross-install script pointed `PATH` to a nonexistent NetCDF directory. Run 39607486689 reused the exact retained binaries on a fresh Windows runner with the actual source-built NetCDF directory in `PATH`; both `postgis` and `postgis_raster` loaded. Run 39608219680 reused those binaries again and passed the full shared probe, including topology, SFCGAL and spatial operations. The script now checks the NetCDF directory before probing. Final archive relocation and static checks remain unverified. TIGER Geocoder remains a separate SQL-only archive. Remove this experiment after its findings have been incorporated into the selected Windows publication route or a human review decision.
