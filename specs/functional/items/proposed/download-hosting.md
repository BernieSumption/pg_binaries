# Download hosting

**Decision:** Choose public hosting and publication permissions. GitHub Releases is a candidate; temporary Actions artifacts do not meet the public-download requirement. Publishing permanent releases still requires authorization.

Context: [F12](../../functional-policy.md#f12--downloads-include-redistribution-obligations), [publication architecture](../../functional-architecture.md#verification-and-publication).

**Recommendation for review:** Use public GitHub Release assets for current downloads, with checksum-bearing filenames and staged catalogue activation. Confirm publication authorization and applicable service constraints before implementing this choice.
