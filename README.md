# PostgreSQL binaries project

This repository aims to provide downloadable PostgreSQL binaries and a curated extension catalogue for tools that apply and inspect database schemas. The Rust consumer API is a separate project.

## Project documents

- [Specification](docs/specification.md) — outcomes and invariants the project must preserve.
- [Verification strategy](docs/verification.md) — the evidence required to claim those outcomes.
- [Proposed project plan](docs/project-plan.md) — provisional milestones for implementation. Agents may change the route as they learn.
- [Decisions for review](docs/decisions.md) — items marked `REVIEW:` that need a human choice or a later reassessment.
- [Prior art](docs/prior-art.md) — researched examples and source links.

The specification and verification strategy are the durable contract. The plan is a working aid, not a prescribed build procedure.
