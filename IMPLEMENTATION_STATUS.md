# Spike 2 implementation status

The current implementation goal covers milestones 2–4 in `SPIKE2_MILESTONES.md`: build and verify every selected package and the complete installation locally for macOS ARM64, then do the same for Linux ARM64. Lume supplies the disposable macOS VMs. Linux may use Docker or Lume. GitHub builds are deferred until both ARM64 targets pass their local builds and checks. Earlier GitHub results remain useful evidence but do not satisfy the local milestones. Work already done for later milestones remains in the tree.

The release checker requires all selected archives and build records, rejects mismatched hashes, source selections, build inputs or PostgreSQL ancestry, and tests each package alone, PostgreSQL alone and the complete combination. It writes a JSON report with named check outcomes and continues after combination failures. `build.py select-runs` examines only supplied workflow runs, selects each component from the last run with its named artefact, checks archive hashes, selected inputs, build revisions and PostgreSQL ancestry, and can invoke the release check. Synthetic tests cover record selection, stale inputs, originating runs, replacement selection, failed checks and unsafe archives.
