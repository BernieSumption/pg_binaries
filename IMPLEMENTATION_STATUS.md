# Spike 2 implementation status

The current implementation goal covers milestones 2 and 3 in `SPIKE2_MILESTONES.md`: build every selected package locally for macOS ARM64, verify each archive in a clean VM, then verify the complete installation. Tart supplies the disposable macOS VMs. Restarting a disposable VM after a temporary command-channel failure is ordinary local iteration. No GitHub builds belong to this goal. Earlier GitHub results remain useful evidence but do not satisfy the local milestones. Work already done for later milestones remains in the tree pending a decision on whether to retain or shelve it.
