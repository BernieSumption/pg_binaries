## Schema use and version transitions

[h3-pg](https://github.com/postgis/h3-pg) exposes the H3 geospatial indexing
library through `h3index`, operators and functions used in table/index DDL.
It lives under the PostGIS organisation but remains independently selectable.

The current README reports PostgreSQL 14–18 CI on Linux and macOS. Historical
releases and portable artifacts still need individual verification. Record
h3-pg, underlying H3 library and SQL extension versions separately.

The pre-cutoff v3-to-v4 function renaming illustrates why schemas can require
an older API without adding those releases to our target. More recently,
[4.5.0](https://github.com/postgis/h3-pg/releases/tag/v4.5.0) fixes a btree
comparator and reindexes affected indexes during upgrade.
